# 숏폼 어필리에이트 수집기 (Chrome Extension)

중국 쇼핑 사이트 상품 페이지에서 **상품명 · 이미지 · 영상 후보(mp4/m3u8) · 선택 텍스트**를
추출해 로컬 대시보드(`/api/import-source`)로 전송하는 경량 확장 프로그램입니다.

> 설계 원칙상 확장은 **수집 + 전송만** 합니다. 다운로드·분석·렌더링은 로컬 Python 엔진이 수행합니다.

## 설치 (개발자 모드)

1. 대시보드 서버를 먼저 실행합니다.
   ```bash
   uvicorn server:app --port 8000
   ```
2. 크롬에서 `chrome://extensions` 접속 → **개발자 모드** 켜기.
3. **압축해제된 확장 프로그램 로드** → 이 `extension/` 폴더 선택.

## 사용

1. 상품 페이지(예: 1688, 타오바오)에서 확장 아이콘 클릭.
2. 대시보드 주소 확인(기본 `http://localhost:8000`), 카테고리(선택) 입력.
3. **현재 페이지 수집 → 전송** 클릭.
4. 대시보드에 `usage_status = "확인 필요"` 상태의 프로젝트가 생성됩니다.

## 수집 항목

| 항목 | 방법 |
| --- | --- |
| 현재 URL / 제목 | `location.href`, `document.title` |
| 선택 텍스트 | `window.getSelection()` |
| 상품명 후보 | `h1`, `[class*=title]`, `og:title`, `title` |
| 이미지 후보 | 200px 이상 `<img>` (최대 40개) |
| 영상 후보 | `<video>`/`<source>` + HTML 내 mp4·m3u8 정규식 (최대 30개) |
| source_site | 도메인 매핑(1688/taobao/tmall/aliexpress/jd 등) |

## 주의

- 권리 확인이 필요한 영상은 대시보드에서 `usage_status`를 **확인됨**으로 바꾸기 전까지
  렌더링이 차단됩니다.
- 캡챠/로그인 우회는 하지 않습니다. 로그인이 필요한 페이지는 로그인된 상태에서 수집하세요.
- 아이콘(`icons/icon128.png`)이 없으면 크롬 기본 아이콘으로 표시됩니다.
